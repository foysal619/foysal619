## How I approach quality

```text
Understand risk → design evidence → automate the right checks → observe the signal → improve the system
```

I value automation that is deterministic, diagnosable, and connected to product risk. A green build matters only when the checks behind it are meaningful; a defect report matters most when it helps the team make a better decision.
